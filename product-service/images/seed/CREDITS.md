# Seed Catalogue Image Credits

Every file in this directory is a photograph from [Wikimedia
Commons](https://commons.wikimedia.org/), downscaled to 900px wide and used as
the demo catalogue image for one seeded product. They are referenced from
[`catalogue.sql`](../../../seed-db/catalogue.sql) as `seed/<file>`, which is
what `product.image` stores.

The photographs are of **real laptops**, but Commons does not hold a picture of
every exact model in the demo catalogue. Where it does not, the closest machine
from the same manufacturer and class stands in — the "Photograph of" column
says what was actually photographed, so no image is passed off as a model it is
not.

All of them are Creative Commons or public domain. The CC BY and CC BY-SA files
may be redistributed only with the author credit and licence kept alongside
them, which is what this file is for.

## Refreshing an image

Replace the file, keeping the name, and update its row above with the new
source, author and licence. The filename is what `catalogue.sql` writes into
`product.image`, so renaming a file means editing the seed in the same change.

These files ship in the product-service container image
([`Dockerfile`](../../Dockerfile) copies this directory). Images uploaded
through the UI land in `images/` alongside `seed/` under UUID names, and — see
**OPS-01** in [known-defects.md](../../../../docs/backend/known-defects.md) —
are lost when the container is recreated. The seeded files survive because they
are baked into the image rather than written at runtime.
